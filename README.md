## 🧪 일촌(결합)은 이렇게 판별해요

두 원소 A, B의 전기음성도 차이 `|EN(A) − EN(B)|` 로 대략 판별!

| 차이 | 결합 종류 |
|------|----------|
| ≥ 1.7 | ⚡ 이온 결합 |
| 0.4 ~ 1.7 | 🔗 극성 공유 결합 |
| 0.1 ~ 0.4 | 🤏 무극성에 가까운 공유 결합 |
| < 0.1 | 💞 무극성 공유 결합 |
| 금속 + 비금속 | 🔩 금속 결합 (해당 시) |

> ⚠️ 교육용 근사치예요. 실제 분자는 구조·친화도 등 더 복잡해요!
