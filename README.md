## 🌰 도토리는 뭐예요?

Cy-Chemi 세계의 **작은 화폐**예요. 🌰

- 일촌 성공, 퀴즈 정답, 방명록 쓰기… 하면 조금씩 모여요
- **수소(H)** 미니홈만 처음부터 열려 있어요
- 다른 원소(H~Ne)는 **도토리로 해제**해야 들어갈 수 있어요
- 파도타기로 잠긴 미니홈을 누르면 **「도토리로 열기」** 팝업이 떠요

## 🧪 일촌(결합) 판별법

두 원소 A, B의 전기음성도 차이 `|EN(A) − EN(B)|` 로 대략 판별!

| 차이 | 결합 종류 |
|------|----------|
| ≥ 1.7 | ⚡ 이온 결합 |
| 0.4 ~ 1.7 | 🔗 극성 공유 결합 |
| 0.1 ~ 0.4 | 🤏 무극성에 가까운 공유 결합 |
| < 0.1 | 💞 무극성 공유 결합 |
| 금속 + 비금속 | 🔩 금속 결합 (해당 시) |

> ⚠️ 교육용 근사치예요! 실제 분자는 구조·친화도 등 더 복잡하답니다 ㅎㅎ
