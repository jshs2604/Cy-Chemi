# Cy-Chemi 🧪♡

**주기율표를 싸이월드 감성으로 보는 화학 미니홈피**

원소 프로필 조회, 전기음성도 기반 **일촌(결합) 맺기**, 미니룸, 미니게임까지 — HTML · CSS · Vanilla JavaScript만으로 만든 웹 프로젝트입니다.

## 주요 기능

- **원소 조회** — 1~118번 원소 검색 · 프로필 · 미니홈 (H~Ne 상세)
- **일촌 맺기** — 두 원소의 전기음성도 차이로 이온·공유·금속·무극성 공유 결합 판별
- **결합 실험** — 결합 종류를 직접 비교해 보는 탭
- **미니룸** — 원소별 방 배경 (`원소의 방/`) + 마스코트 (`chem-room.js`)
- **미니게임** — 퀴즈 · 메모리 카드 · 두더지 잡기
- **다이어리 · 게시판 · 방명록 · 동영상** — 싸이월드식 미니홈 구성
- **도토리 상점** — 미니게임·일촌 등으로 모은 도토리로 아이템 구매
- **테마 스킨** — 하늘 / 민트 / 핑크 / 미드나잇 / 모노 / 페이퍼
- **닉네임 입장** — 브라우저 `localStorage`에 저장 (서버 없음)

## 화학 개념 (일촌 · 결합 판별)

두 원소 A, B의 전기음성도 차이 `|EN(A) − EN(B)|`로 대략적인 결합 종류를 판별합니다.

| 전기음성도 차이 | 결합 종류 (개념) |
|----------------|------------------|
| ≥ 1.7 | 이온 결합 |
| 0.4 ~ 1.7 | 극성 공유 결합 |
| 0.1 ~ 0.4 | 무극성 공유에 가까운 공유 결합 |
| &lt; 0.1 | 무극성 공유 결합 |
| 금속 + 비금속 (규칙) | 금속 결합 (해당 시) |

> 교육용 근사치입니다. 실제 분자는 구조·친화도 등 더 많은 요인이 있습니다.
